Scribe keeps your player data persistent, typed end-to-end, and automatically replicated to clients — all from a single shared module. Declare your data shape once, and Scribe generates a typed accessor tree (`data.Coins.Increment(50)`), handles DataStore session locking through ProfileStore, and streams compressed diffs to clients with no RemoteEvents to wire up.

## What Scribe gives you

<CardGroup cols={2}>
  <Card title="Fully Typed" icon="shield-check">
    A type-function-generated accessor tree types your data end to end. `data.Coins.Increment(50)`, nested containers, and datatype fields are all checked at compile time with the new Luau type solver.
  </Card>
  <Card title="Automatic Replication" icon="arrows-rotate">
    Schema-compressed batched diffs stream to clients over a pluggable transport. Read the same data on the client with the same API — no RemoteEvents needed.
  </Card>
  <Card title="Production-Grade Persistence" icon="database">
    Built on ProfileStore's session locking with migrations, a wipe guard, version history, and GDPR export and erase.
  </Card>
  <Card title="Rich Feature Set" icon="star">
    Leaderboards, soft-currency purchases, gifting, player-to-player exchanges, and server-scoped data stores all built in.
  </Card>
</CardGroup>

## Getting started

<Steps>
  <Step title="Install Scribe">
    Add Scribe to your project via Wally or download the `.rbxm` from the [latest release](https://github.com/ericplane/Scribe/releases).
    ```toml wally.toml
    [dependencies]
    Scribe = "ericplane/scribe@2.5.0"
    ```
  </Step>
  <Step title="Create your shared data module">
    One `ModuleScript` in `ReplicatedStorage` declares your template and returns `{ Server, Client }`.
    ```lua ReplicatedStorage/Shared/GameData.luau
    local Scribe = require(game:GetService("ReplicatedStorage").Packages.Scribe)

    return Scribe({
        Template = { Coins = 0, Settings = { Music = true } },
        ProfileStoreIndex = "PlayerData",
        ProfileKeyPrefix  = "PLAYER_",
        Mode = "Mock",
    })
    ```
  </Step>
  <Step title="Read and write on the server">
    Require `.Server` from your shared module and call `WaitForData` before modifying fields.
    ```lua ServerScriptService/PlayerData.server.luau
    local Data = require(game:GetService("ReplicatedStorage").Shared.GameData).Server

    game:GetService("Players").PlayerAdded:Connect(function(player)
        local data = Data.WaitForData(player)
        if data then
            data.Coins.Increment(50)
        end
    end)
    ```
  </Step>
  <Step title="Observe on the client">
    Require `.Client` in a LocalScript — changes replicate automatically.
    ```lua StarterPlayerScripts/PlayerData.client.luau
    local Data = require(game:GetService("ReplicatedStorage").Shared.GameData).Client

    Data.Coins.Observe(function(coins)
        print("Coins:", coins)
    end)
    ```
  </Step>
</Steps>
